# Neo4j Logo Assets

The identity of our brand. This folder contains the full set of Neo4j logo assets across variants, color spaces, and formats. Use the approved digital artwork for all variants of the logo, and use good judgment in applying it.

---

## Logo Colors

The Neo4j logo is available in three colors:

| Color                        | Usage                                                                                                                               |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| **Brand Blue (Dark Baltic)** | Preferred for most use cases on a light background                                                                                  |
| **Black**                    | Use sparingly when hierarchy calls for a more subtle option (e.g., accents on presentation slides, alongside neutral company logos) |
| **White**                    | Use on dark backgrounds                                                                                                             |

To ensure legibility, always keep the color of the logo in contrast with the background color.

---

## Clear Space

A minimum clear space must frame the Neo4j logo. No other design elements may be positioned within this space, including typography, photography, and illustration.

Use the width of the "n" and the included nodes as the proper clear space setting. This width is the clear space for **all sides** of the nameplate.

---

## Monogram Usage

The Neo4j monogram (logo mark) is the shorthand to the full logo. It should only be used when additional branding is present. Make sure either the full logo or the word "Neo4j" is adjacent to the monogram.

## Logo Types

### Full Logo (wordmark + icon)

The complete Neo4j logo with the graph icon and "Neo4j" text.

**Naming pattern:** `logo-{color}-{colorspace}-{background}.{ext}`

| Color      | Files              |
| ---------- | ------------------ |
| Full color | `logo-fullcolor-*` |
| Black      | `logo-black-*`     |
| White      | `logo-white-*`     |

### Logo Mark (icon only)

The Neo4j graph icon without text. Use when the Neo4j name is already established in context.

**Naming pattern:** `logo-mark-{color}-{colorspace}-{background}.{ext}`

| Color      | Files                   |
| ---------- | ----------------------- |
| Full color | `logo-mark-fullcolor-*` |
| Black      | `logo-mark-black-*`     |
| White      | `logo-mark-white-*`     |

## Color Spaces

| Space       | Suffix      | Usage                                         |
| ----------- | ----------- | --------------------------------------------- |
| **RGB**     | `-rgb-`     | Screen, digital, web, presentations           |
| **CMYK**    | `-cmyk-`    | Print production                              |
| **Pantone** | `-pantone-` | Spot color printing (brand-exact color match) |

---

## File Formats

| Format | Extension | Best For                                                        |
| ------ | --------- | --------------------------------------------------------------- |
| SVG    | `.svg`    | Web, presentations, any screen use — scales to any size         |
| PNG    | `.png`    | Screen use when SVG isn't supported — supports transparency     |
| JPG    | `.jpg`    | Email, documents — no transparency, white background only       |
| EPS    | `.eps`    | Print production, professional design tools (Illustrator, etc.) |
| PDF    | `.pdf`    | Print-ready vector, embeddable in documents                     |

---

## Background Types

| Suffix        | Meaning                                                       |
| ------------- | ------------------------------------------------------------- |
| `transparent` | Transparent background — use with PNG, SVG, EPS               |
| `white`       | White/opaque background — JPG files (no transparency support) |

## Things to Avoid

The logo must remain consistent throughout all communications. Adherence to these guidelines ensures the integrity of the identity is maintained.

- **Don't** distort, skew, or stretch the logo
- **Don't** crop the logo
- **Don't** apply outlines
- **Don't** apply gradients
- **Don't** use multiple fill colors
- **Don't** replace Dark Baltic with another color
- **Don't** change the transparency
- **Don't** apply drop shadows
- **Don't** apply the logo over busy backgrounds

---

## Notes

- For this presentation platform, prefer SVG where possible — they're resolution-independent and smallest in file size
